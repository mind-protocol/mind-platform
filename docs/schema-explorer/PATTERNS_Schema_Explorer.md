# PATTERNS — Schema Explorer

## Design Pattern

- Use a **static explanatory page** for v1, optimized for onboarding and consistency.
- Keep schema semantics centralized in protocol docs; this page mirrors, it does not redefine.

## Scope

In scope:
- Route: `app/[locale]/(public)/schema/page.tsx`
- Human-readable descriptions of node/link model

Out of scope:
- DB calls
- Procedural mutation of schema
