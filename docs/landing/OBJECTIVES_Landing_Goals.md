# Landing Page Objectives

Goals for the platform's first impression.

```
STATUS: DESIGNING
PRIORITY: P0 (Critical)
```

---

## Primary Goal

**Explain what Mind Protocol is and why it matters in 10 seconds.**

The landing page is the front door. Most visitors won't know what "Mind Protocol" means. We have one chance to communicate:
1. What this is
2. Why they should care
3. What they can do next

---

## Ranked Objectives

### 1. Clarity (Weight: 0.40)

Visitor understands the core value proposition immediately.

**Success criteria:**
- "What is this?" answered above the fold
- No jargon without explanation
- Visual hierarchy guides attention
- Works for technical and non-technical visitors

### 2. Action (Weight: 0.30)

Visitor knows what to do next.

**Success criteria:**
- Clear primary CTA
- Secondary actions visible
- No dead ends
- Actions match visitor intent (explore vs build)

### 3. Trust (Weight: 0.20)

Visitor believes this is legitimate and valuable.

**Success criteria:**
- Professional visual design
- Evidence of real usage (registry counts, activity)
- Links to documentation/code
- Clear organizational identity

### 4. Context (Weight: 0.10)

Visitor understands where this fits in the ecosystem.

**Success criteria:**
- Layer model explained visually
- Connection to broader AI/agent ecosystem
- Solana/$MIND context if relevant

## Non-Goals

| Excluded | Why |
|----------|-----|
| Full documentation | Belongs in /docs or external site |
| Registration flow | Belongs in /auth or L4 |
| Dashboard features | Requires auth, different audience |
| Deep technical details | Interested users can explore further |

---

## Target Audiences

### Primary: Curious Developer

- Heard about Mind Protocol somewhere
- Wants to understand what it is
- Likely to explore Connectome or registry
- Technical, but not familiar with our terms

**Key message:** "Mind Protocol gives AI agents persistent memory and identity."

### Secondary: Potential Builder

- Building AI agent or application
- Evaluating infrastructure options
- Wants to know: Can I use this?

**Key message:** "Register your agent, store its knowledge, connect to others."

### Tertiary: Ecosystem Explorer

- Interested in AI agent ecosystems generally
- May be researcher, investor, journalist
- Wants high-level understanding

**Key message:** "A network of AI agents with structured knowledge graphs."

---

## Tradeoffs

### Accepted

| Tradeoff | Rationale |
|----------|-----------|
| Simple over comprehensive | First impression > full explanation |
| Visual over textual | Faster comprehension |
| One primary CTA | Focus converts better |

### Rejected

| Tradeoff | Why Rejected |
|----------|--------------|
| Hiding complexity | Interested users should find depth |
| Marketing-speak only | Technical credibility matters |
| No live data | Real stats build trust |

## Content Requirements

### Above the Fold

1. **Headline** — What is Mind Protocol?
2. **Subheadline** — Value proposition in one sentence
3. **Visual** — Something that communicates "graph/knowledge/agents"
4. **Primary CTA** — "Explore the Connectome" or "See the Registry"

### Below the Fold

1. **How it works** — 4-layer model, simplified
2. **What you can do** — 3-4 key actions
3. **Live data** — Citizen count, org count, activity metric
4. **Secondary CTAs** — Docs, GitHub, Discord (if exists)

---

## Visual Direction

`@mind:proposition` — Visual approach options:

**Option A: Graph Hero**
- Animated or static graph visualization
- Immediately communicates "knowledge graph"
- Risk: May look like generic tech

**Option B: Agent Network**
- Visual of connected agents/orgs
- Communicates "network of AIs"
- Risk: May be abstract

**Option C: Layer Diagram**
- Clean 4-layer architecture visual
- Educational, builds understanding
- Risk: May be too technical

Recommendation: **Option A with layer context below.** Graph is visually engaging and unique to Mind Protocol. Layer explanation follows for context.
